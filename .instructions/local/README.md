# Umbrella-Local Instruction Index

This directory owns durable guidance unique to the downstream umbrella, such as
its category vocabulary, integration constraints, publication conventions, and
operator responsibilities.

Do not copy member-local instructions here. Keep bounded integration work in its
authorized task records and promote it only after review establishes a durable
umbrella-owned rule.

Template synchronization must never overwrite, delete, or replace this
directory. Local guidance may narrow or strengthen common umbrella rules but
may not weaken them or extend umbrella authority into members.
